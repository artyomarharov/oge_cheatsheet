Прогрессии

Арифметическая

Каждое следующее число больше или меньше предыдущего на одно и то же число.

aₙ = a₁ + d(n - 1)
Sₙ = a₁ + aₙ2 · n

n - количество членов, a₁ - первый член, aₙ - n-й член, d - разность, Sₙ - сумма.

Геометрическая

Каждое следующее число больше или меньше предыдущего в одинаковое количество раз.

bₙ = b₁ · qⁿ⁻¹
Sₙ = b₁ · qⁿ - 1q - 1

Метод интервалов

(x - 1)(x - 2)(x - 3)(x - 4) ≤ 0
  1. Найти нули числителя: x = 1 или x = 2.
  2. Найти нули знаменателя: x = 3 или x = 4. Они всегда выколотые.
  3. Расставить знаки на числовой прямой.
Ответ: ● → [ ; ○ → (    x ∈ [1;2] ∪ (3;4)

Функции и графики

Этот блок относится к алгебре, но вынесен отдельно, потому что на листах много графических подсказок.

Линейная функция

y = kx + b

k - наклон, крутость. b - высота, коэффициент b равен координате y точки пересечения графика с осью Oy.

Чем больше по модулю k, тем сильнее наклон прямой.

Квадратичная функция

y = ax² + bx + c

a > 0 - ветви вверх. a < 0 - ветви вниз. c - координата y точки пересечения графика с осью Oy.

Вершина параболы:

xв = -b2a

Чтобы построить параболу, находят вершину и несколько точек слева и справа от нее.

Гипербола

y = kx

При k > 0 гипербола находится в I и III четвертях. При k < 0 - во II и IV четвертях. Чем меньше значение |k|, тем сильнее гипербола прижимается к осям.

Углы, параллельные прямые, многоугольники

Вертикальные и смежные углы

Вертикальные углы - углы, стороны которых являются продолжением друг друга. Они равны.

∠1 = ∠2, ∠3 = ∠4

Смежные углы имеют одну общую сторону, а две другие стороны лежат на одной прямой.

∠1 + ∠2 = 180°

Сумма углов

треугольник: 180°
четырехугольник: 360°
пятиугольник: 540°
шестиугольник: 720°

Признаки параллельности

  1. Накрест лежащие углы равны.
  2. Соответственные углы равны.
  3. Сумма односторонних углов равна 180°.
